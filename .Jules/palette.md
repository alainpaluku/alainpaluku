## 2025-05-14 - Branding and Navigation Alignment
**Learning:** Inconsistency in typography (Inter vs. system) and varied badge colors can detract from a "High-Tech" brand identity. Coherent color schemes and a single font (Nunito) reinforce the technical professionalism expected of an Electrical Engineer profile.
**Action:** Standardize all external SVG assets to use 'Nunito', unify all badge colors to the #58A6FF/#0D1117 palette, and enforce uppercase for all section headers. Add a "Quick Navigation" TOC to improve mobile usability for a long README.
